# 山西古建 · 千年木构系列

二十座山西古建的交互式三维科普网站。每座古建均包含历史沿革、专属结构解读、三维模型与拆解体验。

## 在线访问

**https://shanxi-gujian.ok.kimi.link**

原随机网址仍可访问，新网址为当前对外统一地址。

## 主要功能

- 二十座古建独立站点与朝代筛选
- 卫星影像分布地图与建筑图钉
- 360° 旋转、缩放与电影巡游
- 整楼写实模型与结构模型切换
- 逐层拆解、构件散开、粒子爆发与慢镜头
- 节点工坊、柱网平面与内部造像观察
- 每座古建独立的时空长廊与历史场景

## 本地运行

```bash
npm install
npm run dev
```

开发服务器支持通过命令行传入主机和端口参数，例如：

```bash
npm run dev -- --host localhost --port 7100
```

## 构建

```bash
npm run build
```

构建产物位于 `dist/`，可作为纯静态网站发布。

## 技术栈

React、TypeScript、Vite、Three.js、Leaflet、Tailwind CSS。

本项目为古建科普演示作品，史实与结构信息整理自公开资料；三维模型用于交互展示与结构理解。
